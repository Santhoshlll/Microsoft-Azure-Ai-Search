# Microsoft-Azure-Ai-Search

Azure AI Search based intelligent document search system for employees using NLP.

## Features
- **Search Bar**: Intelligent keyword search across documents.
- **PDF Preview**: View search results directly in the browser.
- **Azure Integration**: Powered by Azure AI Search and Blob Storage.

## Setup
1. Clone the repository.
2. Run `npm install`.
3. Create a `.env` file with your Azure credentials.
4. Run `npm start` for local development or `npm run build` for production.
